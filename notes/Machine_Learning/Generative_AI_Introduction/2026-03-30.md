# Deepseek: Manifold-Constrained HC (mHC)

- Connection to Nodes in Model to solve
  - Gradient Vanishing
  - Gradient Explosion
- Type
  - Residual Connection
  - Hyper-Connections (HC)
    - Expand tunnels by adding new trainable matrix for for Residual Connection
    - This introduces potential gradient vanishing/explosion
  - Manifold-Constrained HC (mHC)
    - Constrain the gradient vanishing/explosion in HC
